# Soal 2 — Kerangka Desain Tugas Akhir: Pantau Laut Cirebon

**Tema:** layanan digital pemantauan lingkungan laut dan pelaporan kondisi pesisir. Aplikasi ditujukan untuk nelayan dan petugas terkait agar dapat melihat informasi contoh tentang kondisi laut serta membuat laporan mengenai sampah/limbah, ikan mati, atau air tercemar. Pada versi tugas ini, data masih berupa contoh dan belum terhubung ke GPS atau server.

## Jalankan di VS Code
1. Buka folder `Soal2_Tubes_Pemantauan_Laut`.
2. Jalankan `flutter create .`, lalu `flutter pub get`.
3. Jalankan `flutter run -d chrome` atau `flutter run` untuk emulator/perangkat.

Proyek ini menerapkan named routes, NavigationBar dan NavigationRail adaptif, serta push/pop dengan nilai balik pada formulir laporan. Ganti `nim` pada nama proyek bila diperlukan.
