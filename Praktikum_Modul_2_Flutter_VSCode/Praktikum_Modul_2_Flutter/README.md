# Praktikum Modul II — Flutter

Paket ini berisi dua proyek terpisah sesuai bagian **G. Tugas Praktikum** pada Modul-2.pdf:

1. `Soal1_Nusantara_Cerdas_Mobile` — implementasi Soal 1 Nusantara Cerdas Mobile dengan fitur navigasi yang diminta modul.
2. `Soal2_Tubes_Pemantauan_Laut` — contoh kerangka desain tugas akhir untuk Soal 2. Tema dapat diganti agar sama dengan proyek Tugas PABW milikmu.

Lihat README pada masing-masing folder untuk langkah menjalankan. Flutter SDK harus terpasang pada komputer agar proyek bisa dijalankan. Karena folder platform dibuat sesuai mesin lokal, jalankan `flutter create .` satu kali di dalam folder proyek sebelum `flutter pub get`.
